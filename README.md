# Jeu AWENI × CFAO Green Infra

Application de jeu des deux épisodes du team building CFAO Green Infra (Cotonou, 3 novembre 2026 · Ouidah, 5 novembre 2026), conçue par AWENI DESIGN.

- `index.html` : l'application complète (joueurs et animateurs), synchronisée par Firebase Firestore (projet `jeu-aweni`).
- Mise en ligne : GitHub Pages, branche `main`, dossier racine.
